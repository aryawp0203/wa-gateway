# 1. Buat folder untuk project gateway
mkdir wa-gateway
cd wa-gateway

# 2. Inisialisasi project Node.js
npm init -y

Wrote to C:\laragon\www\wa-gateway\package.json:

{
  "name": "wa-gateway",
  "version": "1.0.0",
  "description": "",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": [],
  "author": "",
  "license": "ISC"
}

---
Langkah 2: Install Dependencies
Kita membutuhkan tiga library utama:

express: Untuk membuat API server (menerima request dari Laravel).

whatsapp-web.js: Core engine untuk WhatsApp.

qrcode-terminal: Untuk memunculkan QR Code di terminal saat login pertama kali.

Jalankan perintah ini:
npm install express whatsapp-web.js qrcode-terminal

---
Langkah 3: Buat Script Utama (index.js)
Buat file baru bernama index.js di dalam folder wa-gateway tersebut, lalu copy-paste kode berikut. Kode ini sudah dilengkapi dengan sistem LocalAuth agar Anda tidak perlu scan QR code berulang kali jika server di-restart.

---
Langkah 4: Menjalankan Server & Scan QR
Di terminal Anda, jalankan perintah:

Bash
node index.js
Tunggu beberapa detik. Terminal akan memunculkan gambar QR Code.

Buka aplikasi WhatsApp di HP (gunakan nomor khusus yang akan dijadikan bot pengirim notifikasi), pilih Perangkat Tertaut (Linked Devices), lalu scan QR code di terminal tersebut.

Jika berhasil, terminal akan menampilkan tulisan: "WhatsApp Gateway sudah siap dan terhubung!".

Mulai titik ini, server Node.js Anda siap menerima request dari aplikasi Laravel Anda.

---
Langkah 5: Cara Menguji API (Testing)
Sebelum menghubungkannya ke Laravel, Anda bisa mengujinya menggunakan Postman, Insomnia, atau terminal cURL.

Contoh request menggunakan cURL
Di Windows PowerShell, pakai curl.exe, bukan curl, karena curl sering dianggap alias bawaan PowerShell.

Jalankan seperti ini di terminal:
curl.exe -X POST http://localhost:3000/send-message `
  -H "Content-Type: application/json" `
  -d '{"number":"085647647074","message":"Halo, ini pesan percobaan dari Node.js Gateway"}'

Kalau mau satu baris:
curl.exe -X POST http://localhost:3000/send-message -H "Content-Type: application/json" -d '{"number":"085647647074","message":"Halo, ini pesan percobaan dari Node.js Gateway"}'

Kalau ternyata kamu pakai Command Prompt, formatnya ini:
curl -X POST http://localhost:3000/send-message -H "Content-Type: application/json" -d "{\"number\":\"085647647074\",\"message\":\"Halo, ini pesan percobaan dari Node.js Gateway\"}"

Syaratnya:
1. server Node.js harus sudah jalan di http://localhost:3000
2. endpoint /send-message harus memang ada di index.js
